# Dataset release v0.2.0

This is a citable research-infrastructure snapshot, not a complete census of EU AI documents, a legal authority, or a completed qualitative coding study.

## Citation

Hao, Yichen (2026). *EU AI Policy Observatory* (Version 0.2.0) [Data set]. GitHub. https://github.com/Riro-deddo/eu-ai-policy-observatory/releases/tag/v0.2.0

Cite the version and full source commit from the release manifest. The live website changes; the release assets do not. No DOI or new licence is assigned. Official source documents retain their applicable rights. Version 0.1.0 remains unchanged.

## Scope and counts

- Coverage cutoff: **4 September 2026**, unchanged by later review.
- Review: **6 September 2026 UTC**, extending into 7 September in Europe/London.
- **218 published document records:** 118 principal, 45 supporting, 31 version and 24 attachment records.
- **214 expanded-evidence verified; 4 qualified published records remain pending.**
- Inventory: 218 included, 18 merged, 10 excluded, 8 pending candidates.
- Published records span **1982–2026**. This does not imply continuous or exhaustive coverage of those years.
- English manifestations are represented. Versions, annexes and procedural records are not independent laws or necessarily independent analytical observations.

## Changes and preserved qualifications

The [34-candidate ledger](../../research/reviews/2026-09-06-candidate-snapshot/candidate-decisions.json) records 26 admissions and 8 pending outcomes. Prior decisions remain in history. Additions include nine Parliament amendment compilations whose exact English PDF issuance is now established; JRC reports; healthcare, finance, migration, workplace and mobility material; and the 1982 ESPRIT pilot decision. The [review report](../../research/reviews/2026-09-06-candidate-snapshot/report.md) explains evidence and limitations.

The [four-record recheck](../../research/reviews/2026-09-06-candidate-snapshot/retained-records.json) changes no qualification: one standardisation decision lacks exact public-release evidence; two July GPAI records share an unresolved MAIN ancestor; one Council INIT retains an official version conflict. Technical ingestion, transmission, meeting dates and a later revision are not substituted for missing facts.

The eight unpublished candidates comprise three AI Board reports, the November GPAI guidelines, an EBA letter, an ECB article, the drones study and draft GMP Annex 22. Reasons vary: exact-version dates, conflicting date meanings, unavailable valid primary bytes or an unresolved annex-parent boundary. They are not excluded and have explicit reopening conditions.

All 192 previously published document files were preserved. Local byte receipts and separately labelled LF-normalised hashes distinguish real record changes from Git checkout line endings. The public source tree retains English reports, metadata receipts, exact URLs and field locators. Full PDFs and multilingual API bodies remain local-only where stated; hashes alone are not a public archive.

## Use in research

The corpus remains expanding and institutionally uneven. Empty policy, concept, sector-completeness or relationship annotations are not negative findings. Some earlier discovery narratives lack reproducible query/result logs. Public maintainer/reviewer credit does not constitute an independently timestamped human sign-off. Dataset authorship and official document authorship remain distinct. See the methodology and data dictionary before defining an analytical sample.

## Reproduction and assets

Assets: `public-data.json`, `eu-ai-policy-observatory.sqlite`, `release-manifest.json` and `SHA256SUMS.txt`. The GitHub source archive preserves canonical records, code, schemas and review ledgers at the tagged commit.

Rebuild from the manifest's exact source commit:

```sh
python -m pip install -e '.[test]'
observatory-build --project-root . --timestamp 2026-09-06T23:16:13Z
python -m pytest -q
```

The manifest records commit, source tree, runtime, cutoff, timestamp and byte hashes. Validate downloaded bytes against SHA256SUMS.txt. SQLite layouts can differ across Python/SQLite platforms despite identical schemas and rows; use semantic comparison for cross-platform reproduction. Website/browser CI must pass before merge and deployment. The release tag is created only at the checked merged commit.
